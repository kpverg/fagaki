# Φαγάκι

## Εκκίνηση

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Στα Windows χρησιμοποίησε `.venv\Scripts\python` αντί για `.venv/bin/python`.
Το πρόγραμμα διαθέτει καρτέλες **Συνταγές** και **Εβδομαδιαίο πρόγραμμα**.
Στις συνταγές προσθέτεις, επεξεργάζεσαι και διαγράφεις φαγητά, με υλικά,
οδηγίες και ένδειξη νηστίσιμου. Η βάση `fagaki.db` δημιουργείται
δίπλα στο `main.py` και τα υπάρχοντα δεδομένα διατηρούνται.
Πάνω από τον πίνακα μπορείς να αναζητήσεις συνταγές με το όνομά τους και να
φιλτράρεις ανά ημέρα. Πάτησε τις επικεφαλίδες για ταξινόμηση· η ημέρα
ταξινομείται με τη σειρά της εβδομάδας. Η αναζήτηση και το φίλτρο συνδυάζονται.
Η εκκίνηση προσθέτει τη διαδρομή των Qt plugins του PyQt5, ώστε να λειτουργεί
και όταν το περιβάλλον βρίσκεται σε φάκελο με ελληνικούς χαρακτήρες.
Από το γρανάζι επάνω δεξιά ανοίγουν οι ρυθμίσεις: χρώμα φόντου και κειμένου
από πλήρη παλέτα, μέγεθος γραμματοσειράς (6–48 pt) και γλώσσα (ελληνικά ή
αγγλικά). Η αποθήκευση εφαρμόζει τις αλλαγές αμέσως και τις διατηρεί για τις
επόμενες εκκινήσεις, ξεχωριστά από τη βάση φαγητών.

## Εβδομαδιαίο πρόγραμμα και αγορές

Στην καρτέλα **Εβδομαδιαίο πρόγραμμα** διάλεξε μια ημερομηνία της επιθυμητής
εβδομάδας και πάτησε **Δημιουργία**. Δημιουργείται πρόγραμμα από Δευτέρα έως
Κυριακή, επιλέγοντας τυχαία από τις συνταγές που ανήκουν σε κάθε ημέρα μέσω
του `fagaki.imera_id`. Οι ημέρες νηστείας του πίνακα `meres` και οι περίοδοι
του πίνακα `nisteies` δέχονται μόνο νηστίσιμες συνταγές. Μπορείς να αλλάξεις
τη συνταγή κάθε ημέρας από τις αντίστοιχες επιτρεπόμενες επιλογές της. Αν μια
ημέρα δεν έχει κατάλληλη συνταγή, εμφανίζεται μήνυμα και το προηγούμενο
πρόγραμμα παραμένει αμετάβλητο. Διατηρείται μόνο ένα πρόγραμμα· η νέα δημιουργία ζητά
επιβεβαίωση πριν αντικαταστήσει το προηγούμενο. Η καταχώριση επιπλέον περιόδων
νηστείας από το UI δεν υποστηρίζεται ακόμη.

Στη φόρμα συνταγής η ημέρα είναι υποχρεωτική. Παλαιές συνταγές χωρίς ημέρα
παραμένουν στη βάση, αλλά δεν επιλέγονται στο πρόγραμμα μέχρι να ορίσεις ημέρα
με επεξεργασία. Αν αλλάξει η ημέρα μιας συνταγής που υπάρχει ήδη στο
αποθηκευμένο πρόγραμμα, επίλεξε άλλη συνταγή για την αντίστοιχη ημέρα πριν
υπολογίσεις τις αγορές.

Επίλεξε ή πρόσθεσε υλικό, μονάδα και θετική ποσότητα και
πάτησε **Προσθήκη υλικού**. Το **Πάμε για ψώνια** αθροίζει τις ποσότητες όλων
των ημερών ανά υλικό και μονάδα. Δεν αφαιρεί απόθεμα. Η λίστα μπορεί να
αντιγραφεί και να σταλεί από τον χρήστη στο κινητό μέσω της εφαρμογής που
επιλέγει· δεν αποστέλλεται αυτόματα.
Νερό, ρίγανη, αλάτι, πιπέρι, ελαιόλαδο και ζάχαρη εξαιρούνται από τη λίστα
αγορών, αλλά παραμένουν στις συνταγές.
Αποθηκεύεται επίσης ως PDF στην Επιφάνεια Εργασίας, με μικρά γράμματα και
αυτόματη σμίκρυνση ώστε να χωράει σε μία σελίδα. Σε πολύ μεγάλες λίστες
τα γράμματα μπορεί να γίνουν πολύ μικρά.
Το ίδιο υλικό μπορεί να χρησιμοποιείται σε διαφορετικές μονάδες, ακόμη και
στην ίδια συνταγή. Στη λίστα αγορών οι ποσότητες διαφορετικών μονάδων
εμφανίζονται χωριστά, εκτός από πατάτες, αλεύρι και δυόσμο, που εμφανίζονται
μία φορά. Ο δυόσμος εμφανίζεται χωρίς ποσότητα. Για πατάτες και αλεύρι, όταν
συνυπάρχουν κιλά και άλλες μονάδες, εμφανίζονται τα κιλά με «>». Αν υπάρχουν
διαφορετικές μονάδες χωρίς κιλά, εμφανίζεται μόνο το όνομα. Δεν γίνεται
αυτόματη μετατροπή.

Κάθε δομημένο υλικό έχει μία κατηγορία, όπως λαχανικά, κρέατα, αλλαντικά,
τυριά ή όσπρια. Το **Πάμε για ψώνια** εμφανίζει τα εβδομαδιαία αθροίσματα
σε πίνακα, ομαδοποιημένα ανά κατηγορία, με ένα row για κάθε υλικό και μονάδα.

Το παλιό πεδίο ελεύθερου κειμένου διατηρείται μόνο για ανάγνωση. Κατά την εκκίνηση
αναλύονται αυτόματα τα υλικά των εισαγόμενων συνταγών, μαζί με απλά κλάσματα
όπως `1/2 κιλό`: τα γραμμάρια μετατρέπονται
σε κιλά, ενώ λίτρα, ml, κουταλιές σούπας και κουταλιές γλυκού διατηρούν τη μονάδα
τους. Υλικά χωρίς ποσότητα καταχωρούνται ως ένα τεμάχιο. Υλικά στη μορφή
`κρεμμύδι, 1, τεμάχια` αναγνωρίζονται αυτόματα αν όλο το κείμενο περιέχει
σαφείς ποσότητες και υποστηριζόμενες μονάδες. Όπου η μετατροπή δεν είναι
σαφής, σύνδεσε χειροκίνητα όλα τα υλικά στη φόρμα συνταγής. Οι αγορές δεν
εμφανίζονται ως πλήρεις όταν μια συνταγή του προγράμματος δεν έχει συνδεδεμένα
υλικά ή λείπουν ποσότητες: εμφανίζεται σχετικό μήνυμα.

## Δομή εφαρμογής

- `main.py`: εκκίνηση της εφαρμογής.
- `screens/maininterface.py`: παράθυρο και φόρμα φαγητού.
- `screens/settingscreen.py`: παράθυρο ρυθμίσεων.
- `screens/weekly_screen.py`: πρόγραμμα και λίστα αγορών.
- `screens/ingredient_editor.py`: επιλογή υλικών και ποσοτήτων συνταγής.
- `services/`: εκκίνηση και λειτουργίες της εφαρμογής.
- `dbservices/`: δημιουργία, αναβάθμιση και πρόσβαση στη βάση.
- `utilities/`: κοινά μοντέλα δεδομένων για τη μεταφορά τους μεταξύ των επιπέδων.
- `assets/`: εικόνες του περιβάλλοντος, όπως το καρότο του φόντου.
- `style/styles.py`: κοινό στυλ, επιλογή χρώματος και εικόνα φόντου.

Η ροή δεδομένων είναι `screens` → `services` → `dbservices`, με τα μοντέλα
`MealData` και `MealSummary` από το `utilities/meal.py`. Το `ui.py` διατηρεί
τα παλιά imports για συμβατότητα.

Η βάση SQLite περιέχει:

- `meres`: ημέρες της εβδομάδας και `isnisteia` (1 για Τετάρτη και
  Παρασκευή, 0 για τις υπόλοιπες).
- `nisteies`: `dtstart`, `dtend` και προαιρετικές `paratiriseis`.
- `fagaki`: όνομα φαγητού (`name`), προαιρετική ημερομηνία (`selectedday`),
  υλικά (`ulika`), συνταγή (`syntagi`), `isnistisimo` (1 ή 0) και προαιρετική
  ημέρα εβδομάδας (`imera_id`, αναφορά στο `meres.id`).
- `ulika`: όνομα (`name`), προεπιλεγμένη μονάδα μέτρησης (`monada_metrisis`: `τεμάχιο`,
  `συσκευασία`, `κιλό`, `λίτρο`, `ml`, `κ.σ.` ή `κ.γ.`), κατηγορία
  (`katigoria`) και `exoapothema` (0 ή 1, προεπιλογή 0).
- `fagaki_ulika`: συσχετίσεις φαγητών και υλικών ανά μονάδα μέτρησης,
  και προαιρετική θετική ποσότητα (`posotita`) στη μονάδα της συσχέτισης.
  Δέχεται και δεκαδικές τιμές· `NULL` σημαίνει ότι δεν έχει οριστεί ποσότητα.
- `weekly_plan`: οι επτά ημέρες του μοναδικού προγράμματος, η εβδομάδα και
  οι επιλεγμένες συνταγές.
- `ingredient_processing`: καταγραφή των συνταγών των οποίων τα υλικά έχουν
  ήδη μεταφερθεί ή επεξεργαστεί, ώστε να μη μετατρέπονται ξανά.

Αποθήκευσε τις ημερομηνίες ως κείμενο σε μορφή ISO 8601, π.χ.
`2026-03-04`. Οι οδηγίες και το παλιό πεδίο υλικών αποθηκεύονται ως κείμενο.
Τα υλικά για τις αγορές συνδέονται με τους πίνακες `ulika` και `fagaki_ulika`.
Το παλιό πεδίο ημερομηνίας `fagaki.selectedday` παραμένει ανεξάρτητο από
το εβδομαδιαίο πρόγραμμα.
Για απευθείας αλλαγές στη SQLite ενεργοποίησε `PRAGMA foreign_keys = ON` στη
σύνδεση, ώστε να ελέγχονται οι αναφορές και να διαγράφονται οι συσχετίσεις
όταν διαγράφεται ένα φαγητό ή υλικό.

Για τους ελέγχους: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest -v`.
Στα Windows PowerShell: `$env:QT_QPA_PLATFORM="offscreen"; .venv\Scripts\python -m unittest -v`.
