# Φαγάκι

Εκτέλεσε `python3 main.py` για να δημιουργηθεί το `fagaki.db` δίπλα στο
`main.py`. Η επανεκτέλεση διατηρεί τα υπάρχοντα δεδομένα.

Η βάση SQLite περιέχει:

- `meres`: ημέρες της εβδομάδας και `isnisteia` (1 για Τετάρτη και
  Παρασκευή, 0 για τις υπόλοιπες).
- `nisteies`: `dtstart`, `dtend` και προαιρετικές `paratiriseis`.
- `fagaki`: όνομα φαγητού (`name`), επιλεγμένη ημερομηνία (`selectedday`),
  υλικά (`ulika`) και `isnistisimo` (1 ή 0).

Αποθήκευσε τις ημερομηνίες ως κείμενο σε μορφή ISO 8601, π.χ.
`2026-03-04`. Τα υλικά αποθηκεύονται ως κείμενο.

Για τους ελέγχους: `python3 -m unittest -v`.
