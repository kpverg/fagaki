# Φαγάκι

## Εκκίνηση

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Στα Windows χρησιμοποίησε `.venv\Scripts\python` αντί για `.venv/bin/python`.
Το πρόγραμμα ανοίγει παράθυρο για προσθήκη, επεξεργασία και διαγραφή φαγητών,
με υλικά, μία συνταγή και ένδειξη νηστίσιμου. Η βάση `fagaki.db` δημιουργείται
δίπλα στο `main.py` και τα υπάρχοντα δεδομένα διατηρούνται.

Η βάση SQLite περιέχει:

- `meres`: ημέρες της εβδομάδας και `isnisteia` (1 για Τετάρτη και
  Παρασκευή, 0 για τις υπόλοιπες).
- `nisteies`: `dtstart`, `dtend` και προαιρετικές `paratiriseis`.
- `fagaki`: όνομα φαγητού (`name`), προαιρετική ημερομηνία (`selectedday`),
  υλικά (`ulika`), συνταγή (`syntagi`), `isnistisimo` (1 ή 0) και προαιρετική
  ημέρα εβδομάδας (`imera_id`, αναφορά στο `meres.id`).
- `ulika`: όνομα (`name`), μονάδα μέτρησης (`monada_metrisis`: `τεμάχιο`,
  `συσκευασία` ή `κιλό`) και `exoapothema` (0 ή 1, προεπιλογή 0).
- `fagaki_ulika`: συσχετίσεις φαγητών και υλικών, χωρίς διπλότυπα ζεύγη,
  και προαιρετική θετική ποσότητα (`posotita`) στη μονάδα του υλικού.
  Δέχεται και δεκαδικές τιμές· `NULL` σημαίνει ότι δεν έχει οριστεί ποσότητα.

Αποθήκευσε τις ημερομηνίες ως κείμενο σε μορφή ISO 8601, π.χ.
`2026-03-04`. Τα υλικά και οι συνταγές αποθηκεύονται ως κείμενο. Η διαχείριση
ημερών δεν περιλαμβάνεται ακόμη στο UI· τα νέα φαγητά δεν έχουν ημερομηνία.
Οι καταχωρισμένες ημέρες εβδομάδας δεν εμφανίζονται ούτε αλλάζουν από το UI.
Το πεδίο υλικών του UI παραμένει ελεύθερο κείμενο και δεν συνδέεται ακόμη με
τους πίνακες `ulika` και `fagaki_ulika`. Δεν μετατρέπεται αυτόματα σε εγγραφές.
Για απευθείας αλλαγές στη SQLite ενεργοποίησε `PRAGMA foreign_keys = ON` στη
σύνδεση, ώστε να ελέγχονται οι αναφορές και να διαγράφονται οι συσχετίσεις
όταν διαγράφεται ένα φαγητό ή υλικό.

Για τους ελέγχους: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest -v`.
